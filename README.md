# python-adsdb-django

`adsdb-django`: a Django database backend for Advantage Database Server, built
on the `adsdb` Python driver. It was hosted on Google Code
(`code.google.com/p/adsdb-django`), linked from the Advantage DevZone, and is
preserved here from the Google Code Archive.

BSD license (`LICENSE`).

## Source

`trunk/` of the project's Google Code `source-archive.zip`, its final state.
Subversion metadata (`.svn/`) is left out.
